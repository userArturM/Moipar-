# Дополнительные исправления Pro 4.0

- Браузерное расширение не заполняет форму, если вкладка изменилась, пока пользователь подтверждал запрос в Windows.
- Повторный запрос по кнопке блокируется до завершения предыдущего.
- Native Messaging host всегда очищает разблокированное хранилище после обращения.
- Локальный файл быстрого входа Windows Hello записывается атомарно с попыткой ограничить права файла. Windows Hello здесь **не** является аппаратным хранилищем ключа.
- Windows Actions проверяет PE-заголовки EXE, размеры файлов и создаёт SHA256-манифест.
- Добавлены регрессионные проверки, доступные без Windows.

РЕАЛЬНОГО Windows GUI/Hello тестирования пока нет; это не независимый аудит безопасности.
