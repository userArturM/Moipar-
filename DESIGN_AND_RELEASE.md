# Мои пароли Pro 4.0 — обновление оформления

## Что действительно изменено
- Цветовая система: глубокий тёмно-синий, голубой акцент, контрастные подписи.
- Увеличены высота строк, отступы верхней панели и минимальный размер окна.
- Новый заголовок рабочего пространства, описание и панель быстрых действий.
- Навигация по категориям с явным заголовком; горячая клавиша Escape блокирует хранилище.
- Добавлена автоматическая проверка контраста текста и согласованности двух тем.

## Состояние
- 28 unit-тестов проходят в Linux/Python. Настоящая проверка Windows Hello, интерфейса Tk на Windows 10/11 и собранных EXE не проводилась.
- Формат `vault.dat` не менялся. Перед установкой новой версии сделайте отдельную резервную копию хранилища.
- Windows Hello использует DPAPI и проверку присутствия пользователя; не является аппаратной изоляцией мастер-пароля.
- Браузерная интеграция экспериментальная. Не применяйте в важном рабочем окружении без полноценной проверки безопасности.

## Подготовка Windows EXE
1. Распакуйте содержимое проекта в корень репозитория `userArturM/Moipar-`.
2. Запустите GitHub Actions / Windows build.
3. Проверьте успешное завершение тестов, PyInstaller, Inno Setup и verify_windows_build.py.
4. Скачайте artifacts `MoiParoli-portable`, `MoiParoli-Setup` и checksums.
5. Проверьте запуск и открытие копии `vault.dat`, затем Windows Hello и расширение браузера на тестовых учётных данных.
