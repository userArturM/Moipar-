# Политика конфиденциальности «Bitora Password Manager»

Дата редакции: 15 октября 2026 года.

Расширение «Bitora Password Manager» сохраняет и заполняет учётные данные через локальное приложение Windows. Для работы требуется отдельная установка приложения. У расширения нет собственного сервера сбора данных, рекламы или аналитики.

## Какие данные обрабатываются

- Адрес текущей страницы и домен — для выбора записей соответствующего сайта и проверки адреса перед заполнением.
- Логин и пароль из видимых полей формы — когда пользователь нажимает «Сохранить с сайта» или включает предложение сохранения для конкретного сайта.
- Логин и пароль выбранной записи — для заполнения формы после отдельного подтверждения в приложении.
- Выбор сайтов, на которых разрешено предлагать сохранение, — в локальных настройках расширения.

Расширение не ведёт общую историю посещений и не наблюдает за содержимым посторонних страниц. Оно обрабатывает поля, распознанные как поля входа; поля с браузерными признаками данных банковской карты исключаются из сохранения и заполнения. Адреса страниц и домены обрабатываются только для выполнения описанных действий и настроек сайтов.

## Где хранятся данные

Учётные данные передаются локальному приложению через Native Messaging и сохраняются в выбранном пользователем зашифрованном хранилище. Пароли не записываются в постоянное хранилище расширения. При двухэтапном входе логин временно удерживается в оперативной памяти с привязкой к вкладке и сайту, не дольше трёх минут. Рабочие запросы также временно содержат необходимые для операции данные.

В памяти браузерного сеанса сохраняется результат последнего действия для вкладки: тип операции, время и общий статус. Он не содержит адрес страницы, логин или пароль. Статус удаляется при переходе вкладки на другой адрес или её закрытии, исчезает после завершения сеанса браузера и не показывается спустя 24 часа.

Мастер-пароль вводится в окне приложения и не передаётся расширению. При использовании Windows Hello PIN вводится в системном окне Windows. Настройка Windows Hello принадлежит связанному приложению; локальные данные быстрого входа защищаются Windows DPAPI для текущего пользователя.

Пользователь выбирает расположение хранилища и резервных копий. Если выбрана облачная папка или пользователь самостоятельно синхронизирует профиль браузера и файлы, передачу этих файлов выполняет выбранный им сервис, а не сервер разработчика расширения.

## Передача и использование

Расширение не передаёт пароли, логины или адреса посещаемых страниц разработчику либо рекламным сервисам и не продаёт данные. Учётные данные используются только для сохранения в локальном хранилище и заполнения выбранного сайта по запросу пользователя. Разработчик не получает удалённого доступа к хранилищу.

Использование данных соответствует политике Chrome Web Store User Data Policy, включая требования Limited Use: данные используются только для заявленной функции сохранения и заполнения и не используются для рекламы, профилирования или определения кредитоспособности.

## Связанное приложение Windows

Отдельное приложение может по запросу пользователя обращаться к GitHub для проверки и скачивания обновлений. При явно запрошенной проверке пароля на утечки оно обращается к Pwned Passwords и передаёт первые пять символов SHA-1 хеша проверяемого пароля; полный пароль не отправляется. Эти сетевые функции отделены от работы расширения. Внешние сервисы получают обычные сетевые сведения, необходимые для обработки запроса, например IP-адрес.

## Управление и удаление

Предложение сохранения отключается для каждого сайта в расширении; соответствующее разрешение браузера отзывается. Удаление расширения удаляет его локальные настройки средствами браузера. Записи, корзина и резервные копии управляются отдельно в приложении. Удаление приложения или расширения не означает удаления выбранного пользователем файла хранилища и его копий.
