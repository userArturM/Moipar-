Мои пароли 4.5

- Окно обновлений со списком изменений и скачиванием установщика с проверкой SHA-256.
- Создание и переименование категорий, цвет и значок, перенос нескольких записей.
- Поиск по нескольким словам, категории, тегам и проблемам безопасности.
- Центр резервных копий: даты, отдельная зашифрованная копия, проверка восстановления, напоминания.
- Сворачиваемая боковая панель, размер текста, ненавязчивые уведомления.
- Улучшено распознавание регистрации, смены пароля и входа в два этапа.
- Дополнена диагностика Windows Hello и обработка его недоступности.

Выпуск без сертификата издателя остаётся неподписанным. Автоматическая подпись
подготовлена для подключения сертификата; сертификат не включается в исходники.
Реальная проверка PIN/биометрии на пользовательском устройстве пока не подтверждена.

Закройте старую программу, включая значок в трее, перед установкой.
После обновления перезагрузите расширение из папки browser_extension каталога установки.
