Bitora password 4.6.2 — значки Windows и исправления интерфейса

- Отдельный файл значка Bitora для ярлыков и списка установленных программ; общий идентификатор окна и ярлыков для панели задач.
- Уведомление Windows об обновлении значков после установки.
- Проверка выбранного логотипа внутри собранных EXE и установщика, а также в установленном ярлыке.
- Множественное выделение сохраняется при сортировке и правом клике.
- Ctrl+A и Shift со стрелками/Home/End выбирают записи с клавиатуры.

Закройте приложение перед обновлением и установите в прежнюю папку. Перезагрузите расширение. Если старый закреплённый значок остался на панели задач, открепите его и закрепите Bitora password заново из меню «Пуск». Хранилище, настройки и привязка Windows Hello сохраняются. Сертификата подписи пока нет.
