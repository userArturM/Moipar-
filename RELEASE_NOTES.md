Bitora Password Manager 4.11.0 — Жемчужный синий

- Выбранный светлый стиль: жемчужно-голубой фон, белые карточки, мягкие синие акценты.
- Плавные переходы между разделами, подсветка карточек, отклик кнопок и мягкий перелив фона.
- Анимации учитывают настройку пользователя; предыдущий переход отменяется при быстрой навигации.
- Первое открытие этой версии включает светлую тему. Последующий выбор темы сохраняется.
- Сохранены компактная навигация и отдельное окно меню приложения в настройках.

После установки перезагрузите расширение в браузере. Существующее хранилище и привязка Windows Hello сохраняются.
