Мои пароли 4.5.2

- Сохранение и заполнение через Windows Hello в окнах браузерного модуля.
- Запрос выполняется фоновой частью расширения и продолжается после закрытия его всплывающего окна.
- Проверка вкладки и адреса перед заполнением, защита от повторных запросов и очистка секретов из памяти после ответа.
- На экране входа показан файл хранилища, доступны выбор другого файла и показ мастер-пароля.
- После неверного мастер-пароля окно заполнения остаётся открытым для повторной попытки.
- Смена мастер-пароля через новое подтверждение Windows Hello для уже открытого хранилища.
- Отмена, поздний ответ Hello, блокировка во время смены пароля и ошибка записи не приводят к смене ключа или перезаписи заблокированного хранилища.

Закройте программу, включая значок в трее, перед установкой обновления.
После установки перезагрузите расширение из папки browser_extension каталога установки.
При смене мастер-пароля Windows Hello нужно включить заново. Старые резервные копии остаются под старым паролем.

Сертификат издателя пока отсутствует. Реальное сохранение и заполнение с Windows Hello на пользовательском устройстве требует ручного подтверждения PIN в системном окне; автоматические проверки не заменяют эту проверку.
