# Мои пароли 4.4

Локальный менеджер паролей для Windows с тёмной и светлой темами, категориями,
генератором, аудитом, TOTP, импортом и зашифрованными резервными копиями.
Хранилище использует AES-256-GCM и scrypt; формат passvault v2 сохранён.

## Скачать и установить

Откройте успешный запуск Windows build в GitHub Actions. В разделе Artifacts:
- MoiParoli-Setup — установщик.
- MoiParoli-portable — приложение без установки.
- MoiParoli-BrowserHost — комплект браузерной интеграции.
- MoiParoli-checksums — размеры файлов и контрольные суммы SHA-256.

Закройте старую программу, включая значок в трее, прежде чем обновлять.
Установщик использует прежний AppId. Данные расположены отдельно от программы
в пользовательской папке APPDATA/MoiParoli или в выбранной папке хранилища.
Перед обновлением сохраните отдельную копию vault.dat и ключевого файла.
Удаление приложения не удаляет пользовательское хранилище.

## Расширение Chrome / Яндекс

1. Установите выпуск 4.3. Установщик автоматически регистрирует связь с Chrome, Яндекс, Edge и Chromium для текущего пользователя.
2. Откройте страницу расширений браузера и включите режим разработчика.
3. Загрузите папку browser_extension из каталога установки. Постоянный ID: odddlefcmbmjphfnglidnmdpdlofmfgn. Старое расширение с другим ID замените новой папкой.
4. Нажмите «Проверить подключение» в расширении. При ошибке: приложение → Инструменты → Браузеры → Восстановить подключение.

Для portable распакуйте весь архив в постоянную папку и восстановите подключение
из приложения. EXE приложения и browser_host.exe должны оставаться вместе.
После переноса папки повторите восстановление.

На HTTPS-сайте кнопка «Заполнить данные» запрашивает мастер-пароль в отдельном
окне Windows; при нескольких аккаунтах предлагает выбор. Форма не отправляется.
Кнопка «Сохранить с сайта» читает логин и пароль из видимых полей и открывает
нативное окно подтверждения. Новый пароль сохраняется в категорию «Из браузера»;
смена пароля того же логина обновляет запись с сохранением истории.

«Предлагать сохранение на этом сайте» отдельно запрашивает разрешение для данного
HTTPS-сайта. После отправки формы появляется окно подтверждения сохранения.
Расширение хранит только предпочтения сайтов, а не пароли. Мастер-пароль не
передаётся браузеру. Отмена не изменяет хранилище.
Домен должен совпадать точно; iframe и нестандартные HTTPS-порты не поддерживаются.
Расширение пока устанавливается вручную, оно не опубликовано в магазинах.

## Windows Hello

Настройки → Windows Hello: включить / отключить. Для включения нужны мастер-пароль
и подтверждение Windows. В EXE включён нативный компонент, использующий
IUserConsentVerifierInterop с HWND окна приложения.

Это экспериментальный быстрый вход. Секрет защищён DPAPI текущего пользователя,
но не привязан аппаратно к жесту Hello. Проверка PIN/биометрии на устройствах
Windows 10/11 ещё требуется. При недоступности компонента используйте мастер-пароль.

## Резервные копии

Файл → Экспорт зашифрованной копии. При восстановлении программа сначала проверяет
расшифровку копии с её мастер-паролем и ключевым файлом, если он нужен.
Прежний файл сохраняется как vault.dat.before-restore.
CSV-экспорт содержит открытые пароли; храните его только до завершения переноса.

## Разработка и проверки

```powershell
py -m pip install cryptography pystray pillow openpyxl pyinstaller
py -m unittest discover -s tests -v
node tools/test_extension.mjs
py moi_paroli.py
```

Сборка выполняется через .github/workflows/build.yml. Она запускает тесты,
компилирует компонент Hello, собирает EXE и установщик, проверяет PE-заголовки,
Native Messaging через настоящий EXE и публикует контрольные суммы.

## Ограничения выпуска

В 4.3 обновлён интерфейс: спокойная светлая тема, синий акцент, скруглённые карточки
и единые стили. Сохранены тёмная тема, новая иконка и ручное разрешение конфликтов:
Инструменты → Разрешить конфликты. Можно выбрать локальную запись, запись с диска
или сохранить обе с отдельными идентификаторами. Пароли в сравнении скрыты.

Проверки интерфейса включают масштабы Tk 125–200%, длинные записи и переход
к поиску/между элементами с клавиатуры.
На узком окне и при крупном масштабе доступны вкладки «Разделы», «Записи»,
«Подробности»; окна ввода прокручиваются и показывают элемент, получивший фокус.
Проверки Chrome выполняются в изолированной
сессии на тестовых HTTPS-страницах с подставным ответом Native Messaging;
В установочном тесте настоящее расширение также соединяется с собранным EXE
через Native Messaging и проверяет версию и поддержку сохранения.
Тест обновления использует прошлый установщик 4.1 из Actions, если артефакт
ещё доступен, и проверяет сохранность тестовых записей, вложений, настроек и копий.
Если старый артефакт истёк, проверяется повторная установка текущей версии.

EXE пока не подписаны: нужен сертификат подписи владельца.
Не завершены проверки биометрии и пользовательских профилей Chrome/Яндекс
на реальных устройствах. Установка, обновление и удаление проверяются в CI. Независимый аудит безопасности
не проводился. Автотесты не заменяют эти проверки.

## Выпуск 4.4

- Плавное появление окна при запуске и открытии хранилища. Анимация отключается в настройках.
- Русский / English: переключатель на экране входа и в настройках. Язык сохраняется; записи не переводятся.
- Мастер-пароль от 4 символов при создании и смене. Для защиты данных рекомендуется длинная уникальная фраза.
- Удаление категории: правая кнопка мыши по категории или Инструменты → Удалить категорию. Записи остаются без категории, включая записи в корзине.
- Восстановлена иконка окна / панели задач; расширение получает ту же иконку в размерах 16, 32, 48 и 128 пикселей.
- Обновления: сначала GitHub Releases, затем последняя успешная сборка Windows build на main. Версия читается из исходника именно этой сборки; неудачные сборки не предлагаются.

Приватный репозиторий требует авторизации GitHub API. В настройках можно указать
fine-grained токен с доступом к этому репозиторию и разрешениями Contents: Read,
Actions: Read. Токен сохраняется отдельно от settings.json, зашифрован Windows
DPAPI для текущего пользователя. Пустое поле сохраняет прежний токен; кнопка
«Удалить токен» удаляет его. Токен не добавляется в URL и не записывается в логи.
Без доступа программа сообщает об этом и предлагает открыть Actions в браузере;
она не объявляет установленную версию последней. Обновление устанавливается вручную.
